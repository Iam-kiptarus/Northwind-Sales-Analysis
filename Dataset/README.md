# Dataset

This project uses the Northwind sample dataset.

The dataset is provided as CSV files for easy import into MySQL and Power BI.

## Tables

- Customers
- Categories
- Employees
- Orders
- OrderDetails
- Products
- Suppliers
- Shippers

## Usage

### MySQL

Import the CSV files into MySQL Workbench and create the tables using the scripts in the `sql` folder.

### Power BI

Load the CSV files into Power BI Desktop using:

**Home → Get Data → Text/CSV**

After importing the tables, create the relationships described in the project documentation.
