# Northwind-Sales-Analysis
Business analysis of the Northwind database using MySQL and Power BI.

## Overview

This project is an end-to-end sales analysis of the Northwind database using **MySQL** and **Power BI**.

The project demonstrates the complete data analytics workflow:
- Data cleaning using SQL
- Business analysis using SQL
- Interactive dashboard development in Power BI
- Business insights through visualizations

---

## Objectives

- Clean and prepare the dataset.
- Analyze sales performance.
- Identify top customers by revenue.
- Evaluate product and category performance.
- Measure supplier contribution.
- Analyze employee sales performance.
- Build an interactive Power BI dashboard.

---

## Dataset

The project includes the Northwind dataset as CSV files located in the `dataset` folder.

These files can be imported directly into:

- MySQL
- Power BI
- Excel

---

## Database Tables

The analysis is based on the following tables:

- Customers
- Orders
- OrderDetails
- Products
- Categories
- Suppliers
- Employees
- Shippers

---

## SQL Analysis

The following business questions were answered:

- Top 10 customers by total revenue.
- Products generating the highest revenue.
- Product categories generating the most revenue.
- Suppliers contributing the highest sales revenue.
- Employees processing the highest-value orders.
- Monthly sales trends.
- Customers purchasing the widest variety of products.
- Suppliers supplying products across the most categories.
